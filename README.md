# Portfolio Website

Personal portfolio website showcasing selected frontend development projects, technical skills, and ongoing work.

The site is intentionally built with a lightweight stack to prioritize clarity, performance, and accessibility, while serving as a central place to explore live project demos and source code.

---

## 🚀 Features
- Clean, responsive layout optimized for desktop and mobile
- Project showcase with clickable live demos
- Links to source code for each project
- Clear overview of skills and technical focus
- Simple, accessible user interface

---

## 🛠 Tech Stack
- HTML5 (semantic markup)
- CSS3
- JavaScript
- GitHub Pages (deployment)

---

## 🧠 Purpose
This portfolio serves to:
- Present selected frontend projects in a clear and approachable way
- Provide direct access to live demos and GitHub repositories
- Track growth over time as projects are updated and expanded
- Act as a single reference point for recruiters and collaborators

---

## 📈 Future Improvements
- Add new featured projects as they are completed
- Improve visual consistency and accessibility
- Expand project descriptions with additional technical details

---
